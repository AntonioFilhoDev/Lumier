# Lumier

Uma landing page simples e elegante para apresentar a marca Lumier, com links para contato, catálogo e redes sociais.

## Visão geral

Este projeto é uma página tipo "link in bio" inspirada em plataformas como Linktree. O objetivo é centralizar os principais acessos da marca em um único lugar, com design clean, moderno e responsivo.

## Funcionalidades

- Layout minimalista e visual premium
- Links para redes sociais e contato
- Branding com identidade visual voltada para luxo e natureza
- Página responsiva para mobile e desktop
- Estrutura simples para fácil manutenção

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Ionicons

## Estrutura do projeto


## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/lumier.git
```

2. Acesse a pasta do projeto:

```bash
cd lumier
```

3. Abra o arquivo `index.html` no navegador ou use uma extensão como Live Server no VS Code.

## Como personalizar

- Troque a imagem do avatar em `assets/avatar.png`
- Ajuste os links no arquivo `index.html`
- Modifique as cores, espaçamentos e estilos em `style.css`
- Altere o texto do perfil e os títulos dos botões conforme a sua marca
